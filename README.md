# hxwl-11 校园视力筛查台账

学校视力筛查的电子化台账：替代手抄表格，自动判定转诊规则，修改留痕防漏人。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖，数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能分区

- **阈值区**：转诊规则集中展示，阈值定义在 `src/thresholds.ts`
  - 裸眼视力 < 4.8
  - 等效球镜（球镜 + 柱镜 ÷ 2）< -0.50D
  - 与本人上次筛查对比，半年眼轴增长 > 0.20mm（按间隔天数折算）
- **操作区**：按学生、年级、筛查日录入双眼裸眼视力、球镜、柱镜、轴位、眼轴；命中规则的记录照常保存并进入待转诊名单，提交结果会提示命中项数
- **待转诊名单**：由台账数据实时推导，逐条写明命中项与实际值
- **数据区**：台账表格，支持按姓名/学号搜索、年级筛选、仅看待转诊
- **留档区**：
  - 修改留档：修改必须填写原因，旧值与新值一并存档
  - 重复提交拦截：同一学生同一筛查日只保留最早记录，被拦截的提交登记在案

## 代码结构

- `src/types.ts` — 数据模型（记录、修改留档、拦截留档）
- `src/thresholds.ts` — 阈值常量与转诊规则判定
- `src/ledger.ts` — 台账操作（提交判重、修改留旧值、本地持久化）
- `src/seed.ts` — 首次打开的示例数据
- `src/App.tsx` — 页面（五个分区）
